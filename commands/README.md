# Commands

`seo-audit.md` is the `/seo-audit` slash command. `install.sh` copies it into
every agent's commands directory:

| Agent | Destination |
|---|---|
| Claude Code | `~/.claude/commands/seo-audit.md` |
| Codex | `~/.codex/commands/seo-audit.md` |
| omp | `~/.omp/agent/commands/seo-audit.md` |
| `.agents` standard | `~/.agents/commands/seo-audit.md` |

Usage: `/seo-audit https://example.com`
